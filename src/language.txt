GldeTK scene language
=====================

Scene files live in GldeTK/scenes/*.scene and are copied next to the executable.
F5 reloads the scene at runtime. The parsed scene is compiled every physics tick
into a vec4 program (see GldeTK/Scene/SceneOpcodes.cs), which is evaluated both by
the CPU physics (Scene/SceneVM.cs) and by the shader (map() in shaders/fragment.c).

===PRIMITIVES
Optional "color (r, g, b)" may follow the arguments.

	sphere r
	box (sx, sy, sz)			half sizes
	plane (nx, ny, nz) dist		normal, offset along the normal
	cylinder r halfHeight		along Y
	torus R r					in XZ plane, big and small radius

===DOMAIN OPERATIONS
Transform the position for the elements of the block, the block is a union.

	translate (x, y, z) { ... }
	repeat (cx, cy, cz) { ... }	period per axis, 0 disables repetition along the axis
	rotate (degX, degY, degZ) { ... }	object rotation R = Rz * Ry * Rx
	scale s { ... }

===OBJECT OPERATIONS
	union { a b ... }
	subtract { a b ... }		a minus all the rest
	intersect { a b ... }
	smooth k { a b ... }		smooth union with radius k

The top level of a file is an implicit union.

===EXPRESSIONS
	numbers, t (physics time in seconds), pi
	+ - * /, unary minus, parentheses
	sin(x) cos(x) abs(x) min(a, b) max(a, b)

Arguments of an element are separated by spaces, so arithmetic in a separate
argument must be parenthesized: sphere (1 + 0.2 * sin(t)).
Inside a vector any expression is allowed: repeat (10, 10 + sin(t), 10) { ... }

Comments start with # and last to the end of the line.

===EXAMPLE
	plane (0, 1, 0) 0
	repeat (10, 10 + sin(t), 10) { sphere 1 color (1, 0.55, 0.45) }
	subtract { box (2, 2, 2)  translate (0, 1, 0) { sphere 2.5 } }
	smooth 0.5 { sphere 1  rotate (0, 90, 0) { torus 1 0.2 } }
